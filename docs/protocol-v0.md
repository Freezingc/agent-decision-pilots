## 范围与判断标准

本轮对应四个已讨论的候选问题。目标是排除缺乏可利用空间的题目，并为一个方向产生后续研究依据。小型模拟不等于真实 Agent 改进；强假设下的理想上限不等于可部署算法。禁止把不同任务上的百分比直接比较为选题排名。

用户明确授权先设计并动手做最小验证；本轮不使用付费 API，不做大规模训练，不干扰已有 GPU 作业。模型如可用，先复用已缓存 Qwen2.5-Coder-7B-Instruct；其结果仅支持该模型及本协议范围。新项目单独保存。

## P1：不可靠观测下的恢复决策

假设：当重复写入有损失、状态可见性延迟且检查动作有不同成本时，基于历史观测的短期信念规划能在成功率和成本之间优于固定重试／退避规则。

先做可穷举的状态化模拟，比较立即重试、固定等待后检查、连续一致检查、网格调参的固定规则与信念规划；所有方法具有相同动作集和观测。明确标注规划器是否知道模拟器参数。开发和测试使用不同随机种子；保留一种延迟或噪声条件检查失配。输出逐实例轨迹与终态、重复操作、成本、弃权；不以加权分数掩盖成功率下降。

继续条件：在成功率或重复操作风险相近时，有不能被开发集选出的简单规则解释的成本优势。若只在准确知道生成参数时成立，结论限定为上限诊断，需后续估参验证。

## P2：不确定记忆更新

假设：对开放域更新关系采用“合并／保留／暂缓”的选择策略，能减少新信息错误覆盖旧信息，同时保持真正更新的召回。

优先公开真实基准的数据与标签，冻结抽样和开发／测试划分。比对最新优先、模型直接判断以及保守的选择性合并；至少报告误合并、漏更新、有效覆盖率和调用／token 成本。所有模型策略只读取可公开的对话，不读取隐藏标签；数据适配脚本保留来源和哈希。

若仅以提高拒绝率减少误合并，且同覆盖率的固定阈值无差异，不认定为算法收益。若公开数据无法适配，则清楚报告障碍，不能用自建模板冒充真实基准结果。

## P3：多次跳步的组合空间

假设：两个步骤的干预有非加性，联合观察的控制策略可能比最多一次跳步有额外成本—质量空间。

冻结一个小模型，准备可客观判分的三阶段流程：初答、根据公开样例反馈修复、独立终审修订。两个可跳节点都输出完整代码，因此都能够改变最终答案；不采用“审查只写评语，跳过修订后审查必然无用”的退化设计。采集四种真实运行组合；每题两个采样种子。冻结抽样为此前尚未分析的 MBPP+ heldout 中按哈希排序的 96 题，48 题开发、48 题测试；避免同题不同随机种子跨集合。保存所有分支的响应、实际 token 成本与标签。理想组合选择仅用于上限，不能作为可部署效果。

推理只读取公开题面、公开样例的执行状态与当前代码。隐藏参考解和 MBPP+ 附加测试在推理全部完成后单独判分。四分支共享初答及修复前缀以节省实际采集费用，但每条策略的逻辑 token 成本按其真实执行路径单独核算；不得把已执行又舍弃的步骤算作免费。新增代码冻结时记录所有提示与任务 ID 的哈希。

第一关：联合分支的理想上限是否超出最佳单跳策略。第二关：冻结的廉价门控在测试集上能否利用该空间。固定跳步、依据可见初答信息的门控均为必要对照。增益不足、主要来自跳过无用固定阶段或门控成本抵消收益时，停止这一机制。

## P4：工具探查与用户澄清

假设：允许先进行便宜的环境探查、再选择是否澄清，可在部分信息来自环境、部分来自用户的任务上提高净效用。

先构造明确区分用户偏好和环境属性的信息获取模拟，比较从不问、总是问、先探查再问、短期价值规划。做信息来源与成本条件迁移，检查简单的固定策略是否已足够。此项只验证问题结构，不作为语言理解或真实用户效果证据。

若最强固定策略已达到同等效果，或结果由人为成本设置完全决定，则不推进真实交互实验。

## 分析与复现

核心比较使用配对任务。对随机模拟报告重复种子，对语言模型报告任务聚类的不确定性和原始计数。开发用于参数选择，测试用于报告；不得观察测试结果后反复改规则。复现实验和测试验证先检查数据泄漏、轨迹实际执行、成本核算与终态判分。所有结果是探索性，不作罕见伤害率认证或发表承诺。

长任务使用硬超时及进程日志。依赖安装或执行失败先诊断，修正后另记命令及原因；不把未完成运行计为结果。
